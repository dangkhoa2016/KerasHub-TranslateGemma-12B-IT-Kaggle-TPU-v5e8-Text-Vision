# Code of Conduct

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](CODE_OF_CONDUCT.vi.md)

## Our standard

We want technical discussion in this repository to be useful, respectful, evidence-driven, and welcoming to contributors with different levels of experience.

Examples of constructive participation include:

- focusing criticism on code, behavior, evidence, and reproducible results;
- explaining assumptions and limitations;
- sharing minimal reproduction steps when reporting defects;
- giving credit for prior work and external sources;
- accepting correction when evidence changes the conclusion.

Unacceptable behavior includes:

- harassment, threats, personal attacks, or discriminatory language;
- publishing another person's sensitive information without permission;
- intentionally posting credentials, tokens, or exploitable details;
- repeatedly derailing technical discussion after maintainers request focus;
- misrepresenting test results or claiming accelerator validation that did not occur.

## Enforcement

Repository maintainers may edit, hide, lock, or remove contributions that violate this standard and may restrict participation when necessary to protect the project community.

## Reporting

If a conduct issue also contains a security vulnerability or sensitive information, follow [SECURITY.md](SECURITY.md) instead of posting details publicly.

For ordinary project support, see [.github/SUPPORT.md](.github/SUPPORT.md).
